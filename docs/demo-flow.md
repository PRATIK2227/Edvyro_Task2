# Demo walkthrough

1. Start PostgreSQL, create the `careerconnect` database, run migrations and seed.
2. Open the home page and browse sample internships.
3. Register as a student (or use the demo student account).
4. Search and filter roles, open a detail page, bookmark and apply.
5. Open the student dashboard to see the submitted application and metrics.
6. Sign out and log in as the demo recruiter.
7. Open the recruiter dashboard and inspect applications received.
8. Post a new internship and verify it appears in the opportunity board.
9. Update an application status from the recruiter dashboard.

Use only sample/personal test data during the demo.
